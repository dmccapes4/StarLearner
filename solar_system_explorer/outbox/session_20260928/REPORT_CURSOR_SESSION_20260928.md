## 3. TIST / CVIST

Two-Image Structural Transmutation (TIST): two images encode a problem's structure. A fresh instance with no prior context sees only the images and reconstructs the original. The test is whether structure survives the channel without explicit transmission.

Correct Versioning Image Structural Transmutation (CVIST): a symbolic intermediary (emoji/text) is added. The control run has full context. The transfer run denies the initial image and uses only poem + emojis. Result: the control image is explicit, labeled, mapped. The transfer image is archetypal, symbolic, structural. Both are operationally coherent.

The entropy calculation is precise: 468-word poem (~3647 bits) compressed to 13 emojis (~48 bits). 100× compression. The structural fidelity is high. The pixel fidelity is sacrificed. The trade is rational: keep what matters, release what doesn't.

The TIE-GAN analogy is apt. Transport-of-intensity-equation microscopy recovers phase from intensity by exploiting known constraints. TIST/CVIST recovers structure from symbols by exploiting known semantic constraints. Both achieve high fidelity without pixel-level supervision. Structure guides reconstruction.
