# Body videos

One Theora clip per body, named by its id from `scripts/SolarData.gd`:

```
sun.ogv  mercury.ogv  venus.ogv  earth.ogv  mars.ogv  asteroid_belt.ogv
jupiter.ogv  saturn.ogv  uranus.ogv  neptune.ogv  pluto.ogv
```

These are generated by [`../../tools/build_clips.sh`](../../tools/build_clips.sh) from the manifest
[`../../tools/solar_bodies.tsv`](../../tools/solar_bodies.tsv) (`yt-dlp` download → `ffmpeg` cut →
`.ogv`). Godot 4 plays **`.ogv` (Theora)** only. Re-cut a single body with
`tools/build_clips.sh --id <body>`; the source download stays cached so it's near-instant.

If a clip is ever removed, the video panel falls back to a spoken **"video coming soon"** facts card
for that body, so the app still works.
