## What is ρ?

In the user's framework, **ρ (rho)** is:
> "The continental waveform traveling. Then a step down: fungal and bacterial warfare taking place through humans."

In mathematical terms, ρ here is a **cross-scale autocorrelation** — the same geometric shape appearing at different physical scales, measured by how much each smaller-scale instance resembles the larger-scale template.

```
Standard correlation coefficient:
  ρ = (Σ(xᵢ - x̄)(yᵢ - ȳ)) / (n · σₓ · σᵧ)
  Range: -1 to +1
  ρ = +1: perfect positive correlation
  ρ = 0:  no correlation
  ρ = -1: perfect anti-correlation (mirror)

For cross-scale patterns (fractal correlation):
  We compare the SHAPE of a pattern at scale S₁ with its shape at scale S₂
  ρ_scale = correlation between the normalized pattern vectors at each scale
```

The master template is the **Coriolis betrayal pattern** — a rotating system where:

- The spiral tightens with distance (more deflection at larger r)

**Template vector T** (normalized):
```
T = [entry_angle, deflection_rate, spiral_tightness, recovery_time]
```
