**first guesses** — scrub before shipping.*

## Image fallbacks

None required for Phase 0 — every star and plant media slot has a YouTube candidate.
If a clip fails the content-safety or “on-point” visual pass during scrubbing, replace from the
alts above or add a still under `game/assets/plants/<id>/<kind>.png` and set
`media.<kind>.type` to `"image"` in `seeds.json`.
